# Mapas y ubicaciones

Estado: implementado
Última revisión: 2026-08-02

## Qué puede explicarse al cliente

- Llevo permite buscar lugares y ciudades para completar orígenes y destinos.
- Puede mostrar una vista previa de recorrido y estimaciones para viajes o envíos.
- La aplicación puede solicitar ubicación del dispositivo para mejorar la experiencia de mapas y puntos cercanos.

## Alcance

- Las sugerencias y estimaciones se usan para asistir la carga y visualización de recorridos.
- No sustituyen una confirmación de disponibilidad de conductor.

## No confirmado o no implementado

- No se encontró promesa de precisión exacta de tiempos, distancia, direcciones o ubicación en tiempo real.
- No se debe afirmar seguimiento GPS en vivo de todos los viajes o envíos.

## Preguntas abiertas

- Política de conservación y uso de ubicación.
