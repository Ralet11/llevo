# Operación de conductores

Estado: implementado
Última revisión: 2026-08-02

## Qué puede explicarse al cliente

- Un conductor puede registrar y administrar vehículos.
- Puede publicar, editar o quitar rutas; una ruta incluye recorrido, días, horarios, capacidad y si admite pasajeros.
- Puede marcar días puntuales como no disponibles.
- Para envíos, puede revisar oportunidades, aceptar una entrega, registrar el retiro y registrar la entrega.
- Para pasajeros, puede aprobar o rechazar solicitudes de asiento.

## Alcance

- Aplica a las herramientas disponibles para quien conduce dentro de Llevo.
- La publicación de una ruta no garantiza recibir solicitudes.

## No confirmado o no implementado

- No se encontró asignación automática garantizada de viajes o envíos.
- No se encontró un control operativo humano ni un panel de operaciones ya disponible para clientes.
- Las ganancias mostradas por entregas son estimadas a partir de importes de trabajos completados; no prueban una liquidación cobrada.
