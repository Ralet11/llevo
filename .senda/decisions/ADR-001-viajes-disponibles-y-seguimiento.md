# ADR-001 — Buscar viajes antes de seguir una ruta

Estado: aceptado
Fecha: 2026-08-02

## Decisión

La experiencia de pasajeros busca primero viajes publicados. Si no hay resultado, permite activar un seguimiento de la ruta y fecha.

## Motivo

Simplifica el flujo para la persona que viaja y evita presentar un aviso como si fuera una reserva confirmada.

## Impacto para clientes

Senda debe explicar que el seguimiento avisa sobre nuevas opciones; no garantiza un asiento ni crea un viaje.
